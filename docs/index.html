AetherNet

An open-source, MIT-licensed mesh networking protocol for sharing messages, files, voice, and video with people nearby — with no internet, no servers, and no sign-up. Implemented byte-for-byte identically in eight programming languages.

View on GitHub Read the docs

What it does

Devices connect directly over Bluetooth, Wi-Fi Direct, NearLink, and LoRa. When the recipient is out of range, messages hop through other devices and wait up to 72 hours for a route (delay-tolerant store-and-forward). Every packet is end-to-end encrypted with the Signal Protocol and signed with Ed25519 — relay devices carry what they cannot read. No accounts, no phone numbers, no infrastructure.

  • Messaging, private channels, presence, and profile sync
  • Voice calls, push-to-talk, video calls, screen share, and live streaming
  • SOS broadcast that floods to every device in range — no cell tower needed
  • AODV routing with signed route replies, and erasure-coded storage (Vault)

One protocol, eight languages, identical on the wire

C#RustTypeScriptPythonGoKotlinSwiftC

Every implementation produces byte-identical wire packets, enforced by a shared cross-language fixture corpus in continuous integration — a packet built by one language is decoded, unchanged, by any other. Build your node in any of the eight; it interoperates with all the rest.
