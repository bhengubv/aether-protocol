# AetherNet.Sqlite

SQLite-backed content and map stores for [AetherNet](https://www.nuget.org/packages/AetherNet).

Optional, and its own package because SQLite arrives with a native library for every platform you build for.
That is weight you should choose rather than inherit. Nothing else in AetherNet references it.

MIT. Source at <https://github.com/bhengubv/aether-protocol>.
