# DTN Bundle Replication Strategies

Proves geohash-epidemic and custody-based strategies both preserve bundle conservation.

Properties:
- Geohash strategy: bundle reaches all nodes in same geohash cell
- Custody strategy: bundle reaches destination via single custodian chain
- Neither loses bundles (count conservation per strategy)
